# Instalação / Installation

## PT-BR

1. Extraia `terraria.zip` na pasta de ports. O resultado deve deixar
   `Terraria.sh` ao lado da pasta `terraria/`.
2. Copie seu APK Android legal do Terraria `1.4.5.6.4` para
   `terraria/gamedata/`. O nome do arquivo não importa.
3. Abra `Terraria` no frontend. NXExtract validará e preparará os dados na
   primeira execução; depois, lançamentos válidos usam o marcador verificado.
4. Segure `SELECT+START` por 750 ms para sair.

Se a janela de instalação informar versão incompatível, não renomeie outro
APK: use exatamente a versão suportada. Uma instalação interrompida não
substitui dados válidos, pois a preparação e o commit são transacionais.

## English

1. Extract `terraria.zip` into the ports directory. `Terraria.sh` must sit next
   to the `terraria/` directory.
2. Copy your legal Terraria Android `1.4.5.6.4` APK into
   `terraria/gamedata/`. Its filename does not matter.
3. Open `Terraria` in the frontend. NXExtract validates and prepares the data
   on first launch; later valid launches use the verified marker.
4. Hold `SELECT+START` for 750 ms to exit.

If setup reports an incompatible version, do not rename another APK; provide
the exact supported release. Interrupted setup cannot replace valid data
because preparation and commit are transactional.
